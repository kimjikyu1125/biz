# 오픈케어 (OpenCare) - 소상공인 오픈 필수 설비 올인원 패키지

음식점(외식업) 및 사무실(오피스) 신규 오픈 또는 리뉴얼 시 반드시 필요한 **5대 필수 설비**를 묶어 안내하고 간편 견적을 접수받는 랜딩 페이지 웹사이트입니다.

## 📌 주요 5대 상품 구성
1. **CCTV (ADT캡스)**: 500만 고화질 모니터링 + 24시간 긴급출동 경비 + 안심 배상 보험
2. **인터넷 + 일반전화**: 끊김 없는 기업/상가 전용 기가 인터넷 + 대표번호 & 착신전환
3. **포스기 (POS & 카드단말기)**: IC카드·삼성페이·애플페이 + 배달앱 연동 + 매출 관리
4. **하이오더 (테이블오더)**: 홀 인건비 절감 & 주문 누락 방지 (음식점/카페 특화)
5. **정수기 (업소용/오피스)**: 대용량 스탠드 및 탕비실 직수 정수기 렌탈 (필터/위생 케어)
